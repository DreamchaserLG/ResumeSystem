# 需求分析：简历库 / 人才库 / 文件服务器改造

> 版本：v1.0 · 日期：2026-11-20
> 定位说明：本系统从「招聘管理系统」调整为「**调查系统**」。核心不是管理招聘流程，而是帮使用者**快速找到合适的人**。

---

## 一、产品定位的转变

| 维度 | 旧定位（管理系统） | 新定位（调查系统） |
|------|------------------|------------------|
| 目标 | 走完招聘流程（投递→筛选→面试→录用） | 快速从大量简历里**挑出合适的人** |
| 简历角色 | 挂在岗位下的申请 | 独立的「人才原料」 |
| 岗位角色 | 流程的归属 | 仅作为简历的**提取分类标签**，人可被调剂 |
| 流程管理 | 跟进/面试/调剂/录用一条龙 | 只在「人才库」里做重点跟进 |

**核心矛盾**：简历最终不一定属于提取时的岗位（可被调剂），所以岗位不能作为硬约束，只能作为"先按这个方向提取"的参考分类。

## 二、功能需求拆解

### 2.1 三大实体

```
简历库（原料池）          人才库（精加工池）
─────────────────        ─────────────────
· 自动流入（文件服务器）   · 从简历库复制转入
· 无跟进、无面试          · 有跟进（@同事/附件/删除）
· 只浏览/筛选/挑人        · 有状态 + 面试安排
· 可打能力标签            · 可打能力标签
─────────────────        ─────────────────
        └──────── 复制 ────────┘
        （同一个人可同时存在于两库）
```

### 2.3 需求澄清结论（已与用户确认）

1. **人才库排序规则** = 「人才库置顶」（`in_talent DESC` 优先，其余按原排序）。
2. **复制语义** = 同一候选人可同时在简历库和人才库；简历库卡片加「人才库」徽标。
3. **黑名单** = 正常展示，但带明显黑名单标签（不是隐藏）。
4. **筛选交互** = 悬浮抽屉浮层（从侧边滑出，覆盖在列表上方，带返回）。
5. **岗位联动** = 超管先选部门 → 再看到该部门岗位；不能直接选岗位。普通 HR 仍直接看自己部门岗位。
6. **文件服务器** = 本机只保留接口方法（登记表 + 预留接口），**不实现定时扫描**，等后续提供文件服务器地址。

## 三、关键设计决策

### 3.1 复制 vs 移动
采用**复制**：`talent.candidate_id` 建唯一索引，重复放入幂等返回 `duplicate: true`。简历库与人才库是两套独立视图，不互相删除。

### 3.2 能力标签（R13）——基建复用，不新建表
系统在 `015_skill_taxonomy.sql` 中**已有** `capability_group`（23 个能力分组）和 `skill.capability_code` 映射，`cards.py` 里已有 `capabilities` 查询。本次只需：
- 把 `capability` 加入 `facet_options`（候选值动态来自 `capability_group.code`）
- `/hr/options` 返回 `capabilities` 列表供前端渲染

**后续向量化自动打标**：届时在 `resume_skill` → `capability_group` 的映射上做语义归类即可，表结构已就绪。

### 3.3 文件服务器（R14）——本机只留接口
本机只落 `resume_dropfile` 登记表（object_key/sha256/mime/status），**扫描逻辑在另一台机器实现**。等文件服务器地址到位后，补一个 Celery beat 定时任务扫描目录 → 登记 → 复用现有解析流水线。

### 3.4 状态颜色字典（R11）
后端统一下发，前端按 color 渲染：

| 状态 | code | 颜色 |
|------|------|------|
| 面试进行中 | `interviewing` | `#2F80ED` |
| 录用 | `hired` | `#27AE60` |
| 淘汰 | `rejected` | `#EB5757` |
| 黑名单 | `blacklist` | `#4F4F4F` |
| 自定义 | `custom` | `#9B51E0` |

### 3.5 人才管理页视觉区分（R15）
- 简历管理 = 左右分栏 + 纵向列表
- 人才管理 = **卡片网格 + 状态看板 + 详情抽屉**，配色更醒目，一眼可辨
