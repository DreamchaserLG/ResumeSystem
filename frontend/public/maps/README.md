# 招聘地图底图

全国与省级边界来自 [阿里云 DataV.GeoAtlas](https://datav.aliyun.com/geo/atlas)，在 2026-11-13 下载 `areas_v3/bound/{adcode}_full.json`。本目录保留全国视图（含原数据中的南海线）、省内市级视图及城市定位索引；前端只读取站内文件。边界已简化，仅用于招聘分布展示，城市中心标记是近似位置。未提供市级底图的地区使用省级轮廓。

院校地区、城市来自 [教育部 2026 全国普通高等学校名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A03/202606/t20260618_1441074.html)。可核实的校园图链接另存在院校目录中，点击时才加载官方资源。

离线校图：南京大学[仙林校区官方地图](https://softeng.nju.edu.cn/DFS/file/2021/03/29/20210329113530300x89xc9.pdf)、安阳工学院[官方校园地图](https://www.ayit.edu.cn/2023.10.24ditu.jpg)。这些图仅作校园导览底图，专业统计来自招聘系统。
